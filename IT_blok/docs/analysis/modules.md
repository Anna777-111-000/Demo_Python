## Функциональные модули системы

**1. Пользователи и профили**
* список сотрудников IT-блока
* карточка сотрудника компании (ФИО, почта, телефон, tg, роль, доступы)
* фильтрация по ролям, отделам, статусу (активен/уволен)
* привязка Telegram chat_id

**2. Роли и права**
* управление ролями (создание, редактирование, удаление)
* назначение прав пользователю (несколько ролей у одного человека)
* шаблоны ролей (стандартные наборы)
* оверрайды: добавить/убрать конкретные права поверх роли
* ограничение на количество человек с ролью "глава блока" (например, 1-3)

**3. Запросы админам**
* подача запроса (авторизованные пользователи)
* модерация запросов от гостей (перед отправкой админам)
* приём запроса в работу (кнопка "Взять")
* отображение статуса: новый / в работе / выполнен / отклонён
* история изменений запроса

**4. Доступы сотрудников**
* таблица: у кого какой доступ к сервисам (Git, Jira, VPN, почта, сервера и т.д.)
* выдача/отзыв доступа
* интеграция с HR: автоматическое создание запроса на доступы при приёме нового сотрудника
* срок действия доступа (опционально)

**5. Задачник**
* личные задачи (только свои)
* задачи отдела (видят все в отделе)
* задачи всего IT-блока (видят руководители и при наличии прав)
* дедлайны, статусы, приоритеты, назначения
* фильтры по статусу, отделу, ответственному
* статистика по задачам

**6. База знаний**
* статьи с заголовком, содержанием, тегами, категориями
* поиск по статьям
* разделение по темам: частые проблемы, инструкции, лучшие практики
* кто может писать/редактировать (настраивается через права)

**7. Дашборды**
* общий дашборд по IT-блоку (для начальства и директора)
* дашборды по отделам (для руководителей отделов)
* персональный дашборд (для каждого сотрудника)
* ручной ввод активности (для задач, которые не фиксируются автоматически)
* автоматические метрики: закрытые задачи, выполненные запросы, написанные статьи и т.д.

**8. Уведомления**
* Telegram-уведомления (личные)
* веб-уведомления в интерфейсе
* уведомления о новых запросах, изменениях статуса задач, назначениях

**9. Аудит и логи**
* запись всех действий пользователей (кто, когда, что сделал)
* запись изменений прав (кто, кому, что изменил, было → стало)
* просмотр логов с фильтрацией по пользователю, действию, дате, объекту
* защита от удаления логов (никто)

**10. Предложения (Suggestion Box)**
* подача предложений от гостей и сотрудников
* анонимные предложения (опционально)
* голосование за предложения (лайки/дизлайки)(опционально)
* статусы рассмотрения: на рассмотрении, принято, отклонено, в плане

**11. Чат (будущее, пока заглушка)**
* общий чат IT-блока
* чаты по отделам
* личные сообщения
* уведомления о новых сообщениях
